# Sayeed Portfolio

A responsive React portfolio built with Vite. It uses an editorial layout, warm paper tones, mint and coral accents, and reusable data-driven cards.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build` and preview it with `npm run preview`.

## Personalize

- Update content in `src/data/`.
- Replace placeholders in `src/assets/images/`.
- Add your resume as `public/resume.pdf` and profile image as `public/profile.jpg`.
- Update social URLs in `src/data/socialLinks.js`.

The requested media directories are present with `.gitkeep` files so they are ready for your assets.
